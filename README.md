# Brisa Caribe Tours — inicio del proyecto

Proyecto inicial de Windows Forms en C# para .NET 10, basado en el II parcial de Programación II. El nombre de la agencia es una propuesta editable.

## Abrir en Visual Studio Community

1. Descomprima la carpeta.
2. Abra `AgenciaTours.sln` o `AgenciaTours.slnx`.
3. Seleccione el proyecto `AgenciaTours` y presione F5.

## Qué incluye este inicio

- Proyecto configurado para `net10.0-windows` y Windows Forms.
- Carpetas `Logica`, `Interfaz`, `Properties` y `Resources`.
- Formularios iniciales `Form1` y `FrmReserva`.
- Clases vacías de lógica con comentarios TODO para completar junto con la guía.

Las ventanas están vacías intencionalmente: el siguiente paso es diseñar los controles requeridos y aprender a implementar cada clase. Este archivo aún no es el programa final del examen.

## Identidad provisional

- Agencia: Brisa Caribe Tours.
- Colores sugeridos: turquesa, verde tropical y arena.
- Mejora sugerida: buscar reservas por nombre del cliente.

## Declaración de apoyo con IA

Se utilizó ChatGPT como apoyo para preparar la estructura inicial del proyecto y organizar los requisitos. La lógica de negocio no está implementada en este inicio y será desarrollada y explicada por el estudiante.
